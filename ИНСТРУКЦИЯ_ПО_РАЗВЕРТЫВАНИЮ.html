Инструкция по развёртыванию и запуску

Документ описывает полную процедуру развёртывания прототипа киоска самообслуживания

на локальной машине: подготовку базы данных, запуск API-эмулятора и запуск

клиентского приложения.

1. Архитектура решения

Система состоит из трёх компонентов, которые запускаются в строгом порядке снизу вверх:

№КомпонентТехнологииПортНазначение
1PostgreSQLPostgreSQL 14+5432Хранилище данных (услуги, провайдеры, пользователи, платежи)
2Provider API EmulatorSpring Boot 3.3.2, Gradle 8.12, Java 177924Эмулятор серверного API. Замещает банковскую платформу Abilling на этапе разработки
3Киоск (клиент)JavaFX 21.0.2, Maven, Java 17—Десктоп-приложение терминала самообслуживания
┌──────────────────────┐     HTTP :7924      ┌──────────────────────┐     JDBC :5432     ┌──────────────┐
│  Киоск (JavaFX)      │ ──────────────────► │  API-эмулятор        │ ─────────────────► │  PostgreSQL  │
│  com.kiosk.KioskApp  │   localhost:7924    │  Spring Boot         │   parodiaMisera    │  (схема БД)  │
└──────────────────────┘                     └──────────────────────┘                    └──────────────┘

Клиент сам не работает с базой данных и не хранит данные локально — все запросы идут

к эмулятору по адресу http://localhost:7924 (адрес задан в ApiClient.java).

4. Шаг 1 — Подготовка базы данных PostgreSQL

⚠️ Эмулятор запускается в режиме ddl-auto: validate — он не создаёт таблицы сам,
а лишь проверяет, что они уже существуют и совпадают со схемой. Поэтому схему нужно
создать до первого запуска эмулятора.

4.1. Создать базу данных

# psql из стандартной поставки PostgreSQL
psql -U postgres -c "CREATE DATABASE \"parodiaMisera\";"

Параметры подключения по умолчанию (заданы в application.yml эмулятора):

  • URL: jdbc:postgresql://localhost:5432/parodiaMisera
  • Пользователь: postgres
  • Схема: public

4.2. Создать таблицы

Выполните SQL-скрипт из файла схема БД.md (раздел «Обновлённый SQL»). Он создаёт все

таблицы, индексы, расширение pgcrypto и заполняет справочники CommissionLevel и Roles.

# сохраните SQL-скрипт в файл schema.sql и выполните:
psql -U postgres -d parodiaMisera -f schema.sql

4.3. Заполнить демонстрационными данными

Скрипт схемы создаёт только пустые таблицы и справочники. Чтобы клиент мог авторизовать

пользователя и показать каталог услуг, нужно добавить хотя бы одного провайдера, счёт,

категорию, услугу и пользователя. Минимальный набор приведён ниже (выполнять после

скрипта схемы):

-- Провайдер (уровень комиссии — на уровне организации)
INSERT INTO Providers (id, fullName, shortName, commLvl)
VALUES ('11111111-1111-1111-1111-111111111111',
        'Демонстрационный провайдер', 'Демо',
        (SELECT id FROM CommissionLevel WHERE name = 'organization'));

-- Счёт провайдера
INSERT INTO Accounts (id, name, ownerName, provId)
VALUES ('22222222-2222-2222-2222-222222222222',
        'Основной счёт', 'Демо',
        '11111111-1111-1111-1111-111111111111');

-- Категория услуг
INSERT INTO CategoryService (id, name, provId)
VALUES ('33333333-3333-3333-3333-333333333333',
        'Коммунальные услуги',
        '11111111-1111-1111-1111-111111111111');

-- Услуга
INSERT INTO ProviderService (id, name, categoryId, provId, accountId)
VALUES (gen_random_uuid(), 'Оплата электроэнергии',
        '33333333-3333-3333-3333-333333333333',
        '11111111-1111-1111-1111-111111111111',
        '22222222-2222-2222-2222-222222222222');

-- Пользователь для входа (логин по email + паролю)
INSERT INTO Users (id, name, email, password, provId)
VALUES (gen_random_uuid(), 'admin', 'admin@kiosk.local', 'admin',
        '11111111-1111-1111-1111-111111111111');

После этого учётные данные для входа в киоск:

e-mail admin@kiosk.local, пароль admin.

Альтернатива ручному SQL: справочные данные можно создавать и через CRUD-endpoint'ы
эмулятора (POST /api/providers, /api/categories, /api/services, /api/users),
но эмулятор всё равно требует готовую схему таблиц.

5. Шаг 2 — Запуск API-эмулятора

5.1. Настроить подключение к БД

При необходимости отредактируйте provider-api-emulator/src/main/resources/application.yml

под свои параметры PostgreSQL:

server:
  port: 7924                 # порт эмулятора (его ждёт клиент)

spring:
  datasource:
    url: jdbc:postgresql://localhost:5432/parodiaMisera
    username: postgres
    password: 09bd2n4d       # ← укажите пароль вашего postgres
  jpa:
    hibernate:
      ddl-auto: validate     # схема должна быть создана заранее (см. Шаг 1)

5.2. Запустить

Из папки provider-api-emulator:

# Windows
gradlew.bat bootRun

# Linux / macOS
./gradlew bootRun

Gradle Wrapper сам скачает Gradle 8.12 при первом запуске (нужен интернет). Эмулятор

поднимется на http://localhost:7924.

5.3. Проверить

# список услуг — должен вернуть JSON
curl http://localhost:7924/api/services

# состояние приложения (Spring Actuator)
curl http://localhost:7924/actuator/health

Оставьте окно эмулятора запущенным — клиент обращается к нему в реальном времени.

6. Шаг 3 — Запуск клиентского приложения (киоск)

6.1. Указать JDK 17

# PowerShell (Windows). Подставьте свой путь к JDK 17.
$env:JAVA_HOME = "C:\Users\User\.jdks\ms-17.0.15"

6.2. Собрать

Из папки kiosk-app:

# если mvn не в PATH — используйте Maven, встроенный в IntelliJ:
$mvn = "C:\Program Files\JetBrains\IntelliJ IDEA 2025.1\plugins\maven\lib\maven3\bin\mvn.cmd"
& $mvn -q compile

6.3. Запустить

Вариант А — через Maven (нужен интернет для плагина JavaFX):

& $mvn javafx:run

Вариант Б — через IntelliJ IDEA:

  1. File → Open → выбрать папку kiosk-app (IDE распознает Maven-проект, дождаться синхронизации).
  2. Убедиться, что в File → Project Structure → SDK выбран JDK 17.
  3. Запустить класс com.kiosk.KioskApp (или Maven-задачу javafx:run).

Вариант В — прямой запуск java (для офлайн-окружения):

Указать JavaFX 21.0.2 (-win.jar-модули из ~/.m2/repository/org/openjfx) в --module-path,

а target/classes и jackson (databind, core, annotations 2.16.1) — в -cp. Главный

класс — com.kiosk.KioskApp, модули — --add-modules javafx.controls,javafx.fxml,javafx.web.

Экран входа отрисовывается и без эмулятора. Для перехода на главный экран и авторизации
эмулятор на http://localhost:7924 должен быть запущен.

7. Порядок запуска (чек-лист)

  1. ✅ Запущен PostgreSQL, создана БД parodiaMisera.
  2. ✅ Выполнен SQL-скрипт схемы + демо-данные (Шаг 1).
  3. ✅ Запущен API-эмулятор (gradlew bootRun), отвечает на http://localhost:7924.
  4. ✅ Запущен клиент (mvn javafx:run), открылся экран входа.
  5. ✅ Вход: admin@kiosk.local / admin → виден каталог услуг.
